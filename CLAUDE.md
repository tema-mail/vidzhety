# vidzhety – модуль виджетов для сайтов владельца

- Основа: ~/.claude/skills/marketolog/references/vidzhety-modul-predlozhenie.md и vidzhety-spravochnik.md.
- Каждая часть кода ≤300 строк (`wc -l src/*`), исполнитель ≤7 КБ gzip своего кода (было 6, подняли 21.10.2026 под боковую панель связи) (печатает `npm run build`).
- Тире только «–» (короткое); длинное тире U+2014 запрещено везде.
- Неотключаемые правила (src/engine.ts, у каждого тест в test/engine.test.ts) не ослаблять и не делать настройкой без «да» владельца.
- Новых типов «колесо», «кто-то купил», «сейчас смотрят N», вечных таймеров и заранее отмеченных галочек в модуле нет – это решение.
- Зависимости: только preact и esbuild. Тесты: `npm test` (node --test на .ts).
- Сайты подключают модуль по docs/integraciya.md; живые сайты (gaz-mag и др.) из этого репо не трогать.
- Коммит после каждого проверенного шага, сообщение на русском.

# Виджеты для сайтов (Astro + Preact)

Один остров на сайт: ярлычок у края, плашка-условие, обратный звонок, окно на уходе (только компьютер),
квиз в шторке, липкая панель «Позвонить / Написать» на телефоне и мультикнопка мессенджеров на компьютере.
Что и когда показывать – в `widgets.json`, а правила против раздражения, за SEO и закон зашиты в движок и не выключаются:

- одно перекрывающее окно за визит, первые 10 секунд – только по клику;
- телефон + страница из поиска: окно по времени становится ярлычком; окно на уходе на телефоне не работает, «назад» не подменяется;
- после заявки (событие `lead-sent` от любой формы) виджеты заявок молчат 90 дней;
- 10% посетителей – контрольная группа на 30 дней без самопоявляющихся виджетов;
- новый виджет выключен (`enabled:false`), тихие страницы `<body data-w-quiet>` – ничего само не появляется;
- пока не сделан выбор cookie – виджеты ждут; Метрика получает события только после согласия;
  на странице без окна cookie (прототип) – `"consent": false`: модуль не ждёт выбора и Метрику не трогает;
- нет памяти браузера – самопоявляющиеся не показываются; колеса, «кто-то купил» и вечных таймеров нет.

## Как устроено

| Файл | Что делает |
|---|---|
| `src/engine.ts` | чистые правила: подходит ли виджет, можно ли показать, кто победил |
| `src/state.ts` | память (localStorage/sessionStorage в try/catch), визит, согласие cookie, очередь Метрики |
| `src/Widgets.tsx` | исполнитель: триггеры, ярлычок, плашка, липкая панель, мультикнопка |
| `src/Dialog.tsx` | окно и шторка (грузится при первом открытии): квиз, форма с пустой галочкой, доступность |
| `src/zhurnal.ts` | журнал решений простым русским – только для демо и проверки, на сайты не ставится |
| `src/vidzhety.css` | вид; цвета – через переменные `--w-*` |

Размер (`npm run build`): в Astro сразу – 5,8 КБ gzip своего кода (Preact у сайта уже есть), окно с формой – ещё 2,4 КБ
при первом открытии; один файл `dist/vidzhety.js` с Preact – 12,5 КБ; CSS – 1,5 КБ.

## Подключить в Astro-сайт

Подробно – `docs/integraciya.md`. Коротко:

```astro
---
import Widgets from 'vidzhety/src/Widgets.tsx';
import 'vidzhety/src/vidzhety.css';
---
<Widgets client:idle src="/widgets.json" />
```

Кнопки открывают виджет атрибутом `data-w-open="callback"`. Форма сайта после ответа сервера «принято» шлёт
`window.dispatchEvent(new CustomEvent('lead-sent', { detail: { source: 'form:montazh' } }))`.

## Демо

```sh
npm i
npm run demo              # собирает dist/ и копирует в demo/
npx serve demo            # или: python3 -m http.server -d demo 8080
```

Открыть `http://localhost:3000/` (или :8080): страница-пример магазина газового оборудования, пульт и журнал решений.
Заявки в демо никуда не уходят – заглушка отвечает «принято» через 0,5 с.
На GitHub Pages демо выкладывает `.github/workflows/pages.yml` (тесты → сборка → папка `demo/`).

## Проверка
